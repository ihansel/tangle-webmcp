## Title

Strand — Visible, Agent-Built Machine Learning in the Browser

## Description

Strand is an independent experiment that extends the open-source Tangle visual
pipeline editor with ten
structured browser tools. A WebMCP-capable agent can inspect and edit the same
graph as the person, validate it, request a one-time approved local run, and read
bounded model results.

This demo trains Product2Vec embeddings for a synthetic product catalogue,
compares churn classifiers, and profiles customer clusters entirely in browser
Web Workers. Graph changes remain visible and undoable; source rows are not
returned through the WebMCP summary tools.

Live demo: [PUBLIC JUDGE-ACCESSIBLE URL REQUIRED]  
Source: https://github.com/ihansel/tangle-webmcp  
Upstream Tangle: https://github.com/TangleML/tangle-ui

Synthetic data only. Results are an educational product demonstration, not
production predictions.
