# Recording checklist

## Preflight

- [ ] Public or approved judge-accessible Site is deployed and tested anonymously.
- [ ] Strict empty-input validation fix is deployed and retested.
- [ ] Fresh Product2Vec recipe is open; permission has not been granted.
- [ ] Churn and clustering reports are pre-run in separate tabs.
- [ ] Browser zoom is 90–100%; capture is 1920 × 1080 or 2560 × 1440.
- [ ] Bookmarks, notifications, personal tabs/data, credentials, and account UI
      are hidden.
- [ ] Cursor and text are legible in a short test recording.
- [ ] Microphone position, room noise, and levels are checked.
- [ ] Exact script and prompts are open on a separate non-recorded device/window.

## Recording

- [ ] Record each shot with two seconds of handles before and after.
- [ ] Show the tool discovery/usage truthfully.
- [ ] Capture the refusal before granting one-time run permission.
- [ ] Show visible run completion and open the real Product2Vec report.
- [ ] Show one human interaction with the report.
- [ ] Capture churn and clustering reports without waiting.
- [ ] Do not reveal access controls, tokens, email addresses, or private tabs.

## Edit

- [ ] Assemble to the 2:38 shot list.
- [ ] Remove dead time and failed takes without hiding product failures.
- [ ] Use no music, or attach proof of the selected track's licence.
- [ ] Add accurate captions; correct WebMCP and Product2Vec spelling.
- [ ] Use restrained zooms/callouts only.
- [ ] Confirm all narration claims match visible evidence.
- [ ] Add the live and repository URLs only after anonymous verification.

## Export

- [ ] MP4/H.264, 1920 × 1080, 30 fps, 12–20 Mbps.
- [ ] AAC-LC, 48 kHz, 256–320 kbps.
- [ ] Voice is clear, unclipped, and intelligible on laptop speakers.
- [ ] Dark UI details are visible after compression.
- [ ] Final runtime is below 3:00, ideally 2:35–2:45.
- [ ] Watch the entire exported file.

## Upload and verify

- [ ] Upload to YouTube with the prepared title/description.
- [ ] Set the visibility required by the hackathon.
- [ ] Add or upload corrected captions.
- [ ] Wait for 1080p processing.
- [ ] Open the URL logged out/in a private window.
- [ ] Verify public visibility, audio, captions, thumbnail, links, and runtime.
- [ ] Add the final URL to `../links.md`, both submission forms, and
      `../submission.json`.
